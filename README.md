# smartdashlib

## About the Project

The project developed the smartdashlib library in Python, which serves as an programming interface (API) to facilitate the integration of IoT devices into a web application [SmartDash](https://smartdash.netlify.app/). The library provides an abstract communication layer, enabling users to effectively manage remote devices without having to delve into the details of the  communication protocol.

## Features and functionalities

Among the key features and functionalities of the library are:
- WebSocket communication - is an implementation of two-way, asynchronous real-time communication with the server using the WebSocket protocol,
- authorization - is an authorization mechanism based on tokens, generated when a device is registered with the application,
- asynchronicity - is the use of the asyncio module to handle operations input/output without blocking, which increases the performance and responsiveness of the applications,
- callback registration - is the ability to assign callback functions to specific virtual pins, which enables flexible response to incoming data.


## Usage examples

To explore simple examples of how to use the library, navigate to the [examples](https://github.com/Crapteep/smartdashlib/tree/main/examples) folder. There you will find three prepared examples: **basic**, **game controller**, and **mouse controller**. Each of them includes instructions on which elements to add to the **SmartDash** dashboard and how to configure them properly.


## Installation and Setup

To use the library, simply clone or copy the code from this repository:
```bash
git clone https://github.com/Crapteep/smartdashlib.git
```
Next, run one of the provided examples (or you can also import the SmartDash class and write your own code :D), making sure to update the **TOKEN** variable with the value generated by the application when a new device is created.

**Note:** If you're running the SmartDash application locally, when initializing an instance of the SmartDash class, you will need to specify an additional server attribute (your backend), and optionally the port, which will most likely be set to "localhost".
```bash
smart_dash = SmartDash(token=YOUR_TOKEN, server="localhost", port=YOUR_PORT)
```
